# Tech Stack

## Backend
- **Lenguaje:** Python 3.11+
- **Framework:** FastAPI
- **Servidor:** Uvicorn

## IA / Machine Learning
- **Proveedor:** Google Gemini
- **SDK:** google-genai
- **Uso:** Análisis de imágenes, análisis facial, recomendaciones

## Procesamiento de Imágenes
- **Librería:** Pillow (PIL)
- **Uso:** Redimensionamiento, validación de formatos

## Frontend (Fase 2)
- **Framework:** React/Next.js
- **Lenguaje:** TypeScript

## Arquitectura
- **Patrón:** Capas (controllers → services → clients)
- **API:** REST
- **Formato de intercambio:** JSON

## Convenciones
- Endpoints bajo prefijo `/api/`
- Responses con status codes HTTP adecuados
- Manejo de errores con mensajes claros
- Código con type hints en Python
