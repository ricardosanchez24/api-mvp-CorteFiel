# Feature 001 - Análisis de Foto con IA
**Fecha:** 23-07-2026 | **Estado:** ✅ Completada | **Sesión:** 1

## Objetivo
Endpoint `POST /api/analyze` que recibe una foto de rostro y retorna análisis facial estructurado vía Google Gemini AI.

## Archivos Creados/Modificados
| Archivo | Acción | Descripción |
|---------|--------|-------------|
| `.env` | Creado | Variable `GEMINI_API_KEY` (usuario pone la key) |
| `.gitignore` | Modificado | Agregado `.env` |
| `mi_app_de_cortes/requirements.txt` | Modificado | Agregado `python-dotenv` |
| `mi_app_de_cortes/app.py` | Modificado | Router + load_dotenv |
| `mi_app_de_cortes/src/clients/ai_client.py` | Creado | Singleton client + structured output |
| `mi_app_de_cortes/src/services/haircut_service.py` | Creado | Validación imagen + orquestación |
| `mi_app_de_cortes/src/controllers/haircut_controller.py` | Creado | Endpoint HTTP |

## Decisiones Clave
| Decisión | Razón |
|----------|-------|
| Modelo: `gemini-3.5-flash` | `gemini-2.5-flash` no disponible para nuevos usuarios |
| Prompt en inglés | Requisito explícito del usuario |
| Variable de entorno via python-dotenv | Evitar hardcodear API key |
| Sin compresión de imágenes | Pendiente para futuro |
| Imports absolutos `mi_app_de_cortes.src.xxx` | Necesario al ejecutar uvicorn desde la raíz |

## Errores y Soluciones
| Error | Causa | Solución |
|-------|-------|----------|
| `ModuleNotFoundError: No module named 'src'` | Imports relativos no funcionaban desde raíz | Cambiar a `from mi_app_de_cortes.src.xxx import` |
| `404 NOT_FOUND: gemini-2.5-flash no longer available` | Modelo deprecado para nuevos usuarios | Cambiar a `gemini-3.5-flash` |
| `AttributeError: _get_client` | Método `get_client` llamado como `_get_client` | Corregir nombre del método |
| `ValueError: GEMINI_API_KEY required` al importar | Singleton instanciado en module-level | Lazy initialization con `_get_client()` |

## API Endpoints Implementados
| Método | Ruta | Descripción | Estado |
|--------|------|-------------|--------|
| POST | `/api/analyze` | Analiza foto, retorna análisis facial | ✅ |
| GET | `/` | Health check básico | ✅ |
| GET | `/health` | Health check con status | ✅ |
| GET | `/docs` | Swagger UI (automático) | ✅ |

## Validaciones Implementadas
| Validación | Tipo Error | Código |
|------------|------------|--------|
| Formato no válido (no JPG/PNG) | 400 | Bad Request |
| Imagen > 10MB | 413 | Payload Too Large |
| Imagen corrupta | 400 | Bad Request |
| Sin API key | 500 | Internal Server Error |

## Respuesta JSON Esperada
```json
{
  "success": true,
  "analysis": {
    "face_shape": "oval",
    "hair_type": "wavy",
    "hair_texture": "thick",
    "skin_tone": "medium",
    "features": ["broad forehead", "defined jawline"],
    "confidence": "high"
  }
}
```

## Para Probar (Postman)
1. Método: `POST` → `http://localhost:8000/api/analyze`
2. Body → `form-data`
3. Campo: key=`file`, type=`File`, value=foto JPG/PNG
4. Requiere: servidor corriendo + `.env` con `GEMINI_API_KEY`
